# 0.5 Git local y pre-commit

- **Fecha:** 2026-11-15.
- **Git:** 2.56.0, rama `main`. El remoto se conecta en la tarea 6.4.

## Hooks de pre-commit

`pre-commit==4.7.0` como dependencia de desarrollo; configuracion en `.pre-commit-config.yaml`.

| Repositorio | Revision | Hooks |
| --- | --- | --- |
| pre-commit/pre-commit-hooks | v6.0.0 | check-yaml, check-toml, check-added-large-files, detect-private-key, end-of-file-fixer, trailing-whitespace |
| astral-sh/ruff-pre-commit | v0.17.3 | ruff-check, ruff-format (misma version que `ruff` en `pyproject.toml`) |
| gitleaks/gitleaks | v8.30.1 | gitleaks (deteccion de secretos) |

- Los hooks que reescriben archivos (`end-of-file-fixer`, `trailing-whitespace`) excluyen `data/` para que nunca toquen el JSON original.
- gitleaks se compila desde el hook; no requiere instalar Go ni gitleaks en el equipo.
