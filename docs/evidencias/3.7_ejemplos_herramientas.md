# Ejemplos reales de entrada y salida de las herramientas

Ejecutados el 2026-11-15 contra el Neo4j de docker compose recien cargado, con el reloj del sistema.
Salidas en JSON con `ensure_ascii` (las tildes de los datos quedan como `\uXXXX`).
Salvo donde se indica, cada siniestro se recorta a sus campos clave; la salida real incluye
vehiculos, personas y narrativa, como en el ejemplo completo de SIN-2025-0001.
