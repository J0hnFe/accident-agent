## JSON original

Se movio `siniestros_raw.json` de la raiz a `data/` con `mv`, sin abrirlo para escritura. El hash se registra en `data/siniestros_raw.json.sha256` (formato `shasum`), verificable con `cd data && shasum -a 256 -c siniestros_raw.json.sha256`.

```
$ shasum -a 256 siniestros_raw.json          # antes de mover
77e2ca6e3f29c838035009cad0f720ef70bbda8138369b23616800cbd1fd8280  siniestros_raw.json
$ cd data && shasum -a 256 -c siniestros_raw.json.sha256   # despues de mover
siniestros_raw.json: OK
```

## Decisiones

- **`.docx` del enunciado:** no se publica (`*.docx` en `.gitignore`); es material de BIT y se cita en el README.
- **Material del enunciado en `docs/enunciado/`:** el `.docx` y `GUIA_PRUEBA_TECNICA.md` salen de la raiz. La guia queda como excepcion al ASCII (en `CLAUDE.md`) porque reorganiza el texto original de BIT.
- **`data/siniestros_raw.json` se publica:** contiene nombres, cedulas y placas, pero lo entrego BIT como datos de la prueba y es necesario para la carga con un solo comando. La PII sigue sin cargarse en Neo4j ni mostrarse.
- **Pruebas de integracion y e2e excluidas por defecto:** `addopts` incluye `-m 'not integration and not e2e'`; `uv run pytest -m integration` las ejecuta.
- **mypy en modo estricto** con el plugin de Pydantic, sobre `src` y `tests`.
- **`OPENROUTER_MODELS` separado por comas:** se anota con `NoDecode` para que pydantic-settings no lo interprete como JSON.
- **Secretos como `SecretStr`:** no aparecen en `repr` ni en logs; una prueba lo verifica.
- **CLI minima** (`accident-agent version`) para que el entry point exista desde el inicio; los comandos reales llegan en la tarea 4.8.

## Problemas encontrados

- Typer trata una aplicacion con un solo comando como si ese comando fuera la aplicacion, y `accident-agent version` fallaba con "Got unexpected extra argument". Se resolvio con un `@app.callback()`.
- mypy marco como innecesarios los `# type: ignore[call-arg]` sobre `Settings(_env_file=None)`: el plugin de Pydantic ya reconoce ese argumento. Se eliminaron.
