# 0.3b Langfuse Cloud: plan gratuito y verificacion de la cuenta

- **Fecha de verificacion:** 2026-11-15.
- **Fuentes oficiales:** https://langfuse.com/pricing y https://langfuse.com/faq/all/api-limits
- **Plan:** Hobby (gratuito), sin tarjeta de credito ("no credit card required").
- **Region elegida:** US, `https://us.cloud.langfuse.com`. Las tres regiones (US, EU, Japon) estan en el plan gratuito; la region solo cambia `LANGFUSE_BASE_URL`, no el codigo.

## Limites del plan Hobby

| Concepto | Limite |
| --- | --- |
| Unidades incluidas | 50 000 por mes |
| Unidad | "any tracing data point sent to the platform -- including traces [...], observations (individual steps: spans, events, and generations), and scores" |
| Acceso a datos historicos | 30 dias |
| Usuarios | 2 |
| Proyectos | Ilimitados |
| Ingesta (`/ingestion`, `/otel`, la que usa el SDK) | 1 000 solicitudes por minuto |
| API general (lectura) | 30 solicitudes por minuto |
| Tamano de carga | 5 MB por solicitud y por respuesta |

- Al superar un limite de tasa la API devuelve HTTP 429 con `Retry-After`; los cupos se comparten entre todos los proyectos y claves de la organizacion.
- Las paginas consultadas no indican que ocurre al superar las 50 000 unidades en el plan Hobby (no hay precio por uso adicional).

## Verificacion de las credenciales

Claves publica (`pk-...`) y secreta (`sk-...`) guardadas solo en `.env`. Llamadas reales (identificadores omitidos):

```
$ curl -u "$LANGFUSE_PUBLIC_KEY:$LANGFUSE_SECRET_KEY" "$LANGFUSE_BASE_URL/api/public/projects"
HTTP 200
project name: My Project | keys: ['id', 'metadata', 'name', 'organization']

$ curl "$LANGFUSE_BASE_URL/api/public/health"
{"status":"OK","version":"4.80.0"}
HTTP 200
```

## Consecuencias para el diseno

- **Consumo estimado:** cada solicitud genera una traza, unas 2 generations (llamadas al LLM) y unos 2 spans (herramientas), es decir, unas 5 unidades. Con el tope de 50 solicitudes diarias de OpenRouter, el uso maximo es de unas 7 500 unidades al mes, el 15 % del plan.
- La ingesta de 1 000 solicitudes por minuto no es un cuello de botella; el SDK envia en lotes y en segundo plano.
- **Nombre de la variable:** el panel y el SDK actuales usan `LANGFUSE_BASE_URL`. Se adopta ese nombre en lugar del `LANGFUSE_HOST` del plan original.
- El SDK de Langfuse no se agrega todavia: entra en la tarea 4.6b, detras del puerto `Tracer`.
